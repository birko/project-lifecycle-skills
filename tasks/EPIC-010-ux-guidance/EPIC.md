# Interaction-design (UX) guidance in the skill set

## Area of concern

What the skills tell an agent about how a user interface should behave: the judgement calls a UI diff or a
prototype is checked against when a project's own rulebook says nothing. Raised from a consumer (Birko.Web /
Symbio), where confirm dialogs guard every reversible action because nothing ever asked the question.

Out of scope: any one consumer's UI framework or rules — those belong to the consumer.

## Success criteria

- A UX baseline exists with one owner, and every skill that applies it points there rather than copying it
- A UI diff or a prototype that a baseline row questions gets a non-blocking, labelled finding, and a rule the
  repo recorded always wins over a row
